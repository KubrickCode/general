# 스마트 Git 커밋 메시지 생성기

한국어와 영어로 커밋 메시지를 생성한다. **한 버전을 선택하여 커밋에 사용한다.**

## 현재 저장소 상태

- Git 상태: !git status --porcelain
- 현재 브랜치: !git branch --show-current
- 스테이징된 변경사항: !git diff --cached --stat
- 스테이징되지 않은 변경사항: !git diff --stat
- 최근 커밋: !git log --oneline -10

## 이 명령의 기능

1. 현재 브랜치명을 확인하여 이슈 번호 감지 (예: develop/shlee/32 → #32)
2. git status로 스테이징된 파일 확인
3. git diff를 수행하여 커밋될 변경사항 파악
4. 한국어와 영어로 간결한 커밋 메시지 생성
5. 브랜치명이 숫자로 끝나면 "fix #N" 추가
6. **한 버전을 선택하여** (한국어 또는 영어) `git commit`과 함께 사용

## 커밋 메시지 형식 가이드라인

간단하고 간결하게 작성. 복잡도에 따라 적절한 형식 사용:

### 매우 간단한 변경사항

```
제목만
```

### 간단한 변경사항

```
제목

문제와 해결책을 한두 줄로 간략히 설명
```

### 표준 변경사항

```
제목

문제에 대한 간략한 컨텍스트

- 해결 방법 1
- 해결 방법 2
```

### 복잡한 변경사항 (드물게 필요)

```
제목

- 문제
  - 문제 측면 1
  - 문제 측면 2
- 해결책
  - 해결 접근법 1
  - 해결 접근법 2
```

**중요한 형식 규칙:**

- 첫 줄(제목): 명령형으로 간결한 요약 (72자 이내)
- 최상위 불릿 포인트 앞에 들여쓰기 없음
- 중첩된 불릿은 복잡한 변경사항에 꼭 필요한 경우에만 사용한다
- 설명은 간결하게 - 장황한 설명을 피한다
- 브랜치명이 숫자로 끝나면 (예: develop/32, develop/shlee/32) 끝에 "fix #N"을 추가한다

## 예시

### 매우 간단

```
README 오타 수정
```

### 간단

```
사용자 로그인 검증 추가

빈 사용자명/비밀번호 제출 방지
```

### 표준

```
데이터베이스 쿼리 성능 개선

큰 데이터셋에서 쿼리가 타임아웃되는 문제

- user_id와 created_at 컬럼에 인덱스 추가
- 5분간 쿼리 결과 캐싱 구현

fix #32
```

### 복잡 (드물게)

```
인증 시스템 리팩토링

- 문제
  - 서버 재시작 시 세션이 유지되지 않음
  - 토큰 갱신 메커니즘 없음
- 해결책
  - Redis 기반 세션 저장소 구현
  - 7일 만료의 JWT 리프레시 토큰 플로우 추가
```

## 출력 형식

명령이 제공하는 내용:

1. 스테이징된 변경사항 분석 (없으면 모든 변경사항)
2. **한국어 버전** 커밋 메시지 (복사 준비됨)
3. **영어 버전** 커밋 메시지 (복사 준비됨)
4. **한 버전을 선택하여** `git commit -m "..."`와 사용

## 중요 사항

- 이 명령은 커밋 메시지만 생성하며 - 실제 커밋은 수행하지 않는다
- **두 버전이 제공되지만, 커밋에는 하나만 사용한다**
- 메시지는 간결하게 - 코드에서 명백한 내용은 과도하게 설명하지 않는다
- 변경사항을 적절히 설명하는 가장 간단한 형식을 사용한다
- 브랜치 이슈 번호(예: develop/32)는 자동으로 "fix #N"을 추가한다
- 선택한 메시지 버전으로 `git commit`을 수동으로 실행해야 한다
